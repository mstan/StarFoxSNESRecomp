# Coverage and correctness survey, 2026-10-18

ROM CRC32: `8FC4E6D0`. SHA-256: `82e39dfbb3e4fe5c28044e80878392070c618b298dd5a267e5ea53c8f72cc548`.

Framework: snesrecomp `48982940` (PRs #183 and #184), with recursively updated main/master dependencies. Generation policy lives in `recomp/generate.toml`; `tools/regen.sh` delegates to the framework. The recipe applies to developer regeneration and the launcher SDK. Generated C is never edited by hand or committed.

The USA runtime uses retail memory and shape bindings, rather than addresses from an expanded upstream assembler layout. God Mode now writes PSHIPFLAGS3 at $14D8, bomb stock at $15AD, and preserves wing pointers $1563/$1565/$1567, matrix scratch and OAM state. The original $03B2B7 read independently identifies PSHIPFLAGS3.

God Nuke observes delayed original-ROM bomb creation for a bounded window after A+R. Nova Bomb and explosion shapes are $AF41 and $ACA1. Retail Andross phase shapes are protected and Spinning Core takes ordinary bomb damage. The pending request is serialized with execution state. The execution extension version changes, so this release does not promise compatibility with earlier save states or netplay builds.

A preflight checks the complete execution extension before the shared loader writes guest state. Old or missing extensions are rejected cleanly, with the current machine preserved; an extra-loader diagnostic alone cannot safely signal failure after restoration has started. The regression exercises rejection from a different live timeline and compares the complete snapshot afterward.

The ROM-backed regression suite covers delayed spawn, pending-request save/load, player-part protection, scratch sentinels, complete state restore, rewind/menu behavior, and replay in a new process. Actual flight was sampled at 32:9 (800 pixels). TCP screenshots now report the completed Enhanced composition instead of the stock PPU surface.

Mission teleports select an original initial script before MainGameInit, preserving original object/player/background initialization. Directly replacing the live script VM pointer is not qualified mission coverage. Initializer surveys do not certify every boss defeat or ending.

The corrected initial-script survey completed all nineteen mission initializers across the three retail courses, with movement/firing samples and 800-pixel completed captures, reaching frame 63822. A separate hard-course Venom pilot exercised the original interior flight. These are assisted mission samples, not full-course completion claims.

Extracted production testing also found that `--frames 3700 ROM.sfc` selected `3700` as the ROM. The custom valued flag is now removed and validated before shared ROM argument parsing. `tests/run_cli_tests.py` checks three positional/explicit-ROM argument orders against the actual executable, plus missing, malformed, negative and overflowing counts.

The Enhanced source submodule moved to kandowontu2/starfox-enhanced. Its current renderer also requires face_material.cpp. Non-promoting historical symbol overlays must not be treated as authoritative retail RAM addresses.

Reference walkthrough: https://gamefaqs.gamespot.com/snes/588690-star-fox/faqs/35945

Automated runs use a dummy output audio device while preserving audio emulation. Release defaults retain normal audio. Private ROMs, full memory captures, journals, and trial profiles remain outside the repository. A successful build or version string alone is not evidence of cross-build netplay compatibility.

Setup-pack generation also requires the native analyzer. The updated shared packager includes it and smoke-tests the staged SDK, so the bundled Python/C++ tools can generate without a Rust installation.
